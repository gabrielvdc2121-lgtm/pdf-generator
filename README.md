# Generador de Autorizacion de Trabajo - PDF

Una plataforma para generar PDFs personalizados de autorizaciones de trabajo.

## Instalacion Rapida

### En Mac:

```bash
# 1. Descargar el proyecto
git clone https://github.com/gabrielvdc2121-lgtm/pdf-generator.git
cd pdf-generator

# 2. Instalar dependencias
npm install

# 3. Iniciar servidor
npm run dev
```

Luego abre en tu navegador: **http://localhost:3000**

## Caracteristicas

- Formulario intuitivo
- Generacion de PDF de 2 paginas
- Almacenamiento automatico
- Descarga directa
- Interfaz moderna

## Uso

1. Completa los campos del formulario
2. Haz clic en "Generar PDF"
3. El PDF se descarga automaticamente

## Archivos Generados

Los PDFs se guardan en la carpeta `pdfs-generados/`
